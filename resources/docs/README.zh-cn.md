Vestige 将音视频播放、转写与文本校对放在同一个工作空间中。一个项目可以包含多份媒体，每份媒体可以保留多次转写结果。校对不会改动转写结果本身：修改与结果分开保存，因此文字始终与录音保持对应。

转写参数相关的帮助请参阅[参数说明](params.zh-cn.md)。

## 快速开始

1. 在“转写”菜单中打开“管理转写后端”和“管理转写模型”，下载一组相互匹配的后端和模型。
2. 新建项目，然后使用“媒体”菜单中的“导入”，或将音频、视频文件拖入窗口。
3. 在侧栏选择媒体并打开转写配置。应用预设，检查执行器、后端文件夹、模型文件夹和参数，然后点击“开始转写”。
4. 在“转写任务”窗口查看进度。完成后，转写正文会显示在编辑器中。
5. 一边播放录音，一边修正正文。
6. 保存项目并选择保存位置。之后的修改会自动保存。

## 项目与媒体

通过“项目”菜单新建、打开、保存或关闭项目。.vestige 项目文件保存媒体引用、转写结果和校对修改，不包含音视频本身。

使用“媒体”菜单中的“导入”，或将媒体文件、文件夹拖入窗口即可添加媒体；拖入单个 .vestige 文件则会打开该项目。导入的媒体列在侧栏中，选中一项即可显示其播放器和转写正文。

- 双击媒体名称可以重命名，磁盘上的文件名不变。
- 使用“媒体”菜单中的“向前移动一位”“向后移动一位”调整顺序。
- “从项目中移除”会把该媒体及其转写结果和校对修改从项目中移除，媒体文件本身不会被删除。

媒体文件缺失、已更改或无法读取时，媒体行会显示相应问题。选择“重新定位”可以重新指定文件，选择“忽略”可以不再提示。Vestige 通过文件大小和完整内容的 XXH3-64 校验值核对文件，仅修改时间变化不会影响核对。文件不可用时，所选媒体仍会显示其转写正文。

## 准备后端与模型

Vestige 不内置转写后端和模型。内置预设已组合好执行器、后端文件夹、模型文件夹和参数。在“管理转写后端”和“管理转写模型”中下载对应资源后，在转写配置中应用预设即可。未提供下载项的后端和模型，需要自行从发布者处下载。

“打开后端文件夹”会打开默认后端目录。每个后端放在独立的子文件夹中，并保留其依赖库和许可声明。所选文件夹或其 bin 子文件夹中应包含 whisper-cli 或 sherpa-onnx-offline（Windows 下带 .exe），不要更改后端程序的名称。也可以选择其他位置的后端文件夹；相对路径以默认后端目录为起点。后端文件夹留空不代表选择默认后端。

“打开模型文件夹”会打开默认模型目录。每个模型放在独立的子文件夹中，按[执行器与模型文件名称](#执行器与模型文件名称)重命名文件后，在转写配置中选择该子文件夹。模型文件必须直接位于所选文件夹中，不要多套一层目录。相对路径以默认模型目录为起点。

## 配置和执行转写

选择媒体后打开转写配置。执行器决定如何调用后端，后端文件夹包含程序，模型文件夹包含模型文件，三者需要相互匹配。

可以在“管理转写预设”中应用一组配置。内置预设不能修改或删除；复制后可以调整名称、文件夹和参数。应用预设后，仍可以只为本次转写调整参数。

开始转写后，任务会进入队列。“转写任务”窗口列出等待中、正在转写、已完成、失败和已取消的任务，以及它们的进度和控制台输出。可以取消等待中的任务或停止正在执行的任务。失败后，点击“查看失败原因”，调整配置再重试。设置中可以调整同时转写的任务数；下载任务与转写共用这一并发上限。

每次成功转写都会作为一份独立结果保留，并记录开始转写时使用的配置。之后修改预设不会改变已有结果。

## 校对

### 编辑文字

在正文中直接输入即可插入、删除或替换文字、换行，也可以剪切、复制和粘贴。所有这些修改都可以撤销和重做。新增的文字带有虚线下划线。将鼠标移到行末可以查看该行是否以换行符结束；新增的换行符同样带有下划线。

修改会保留时间对应：保留下来的原文字符仍指向录音中的位置，因此校对之后，播放标示、跳转和信息查看依然有效。

### 已删除的文字与无语音段

删除原文后，原位置会留下 ▼ 标记。点击标记可以在正文中显示被删除的文字，再次点击则收起。要显示或收起选区内的所有已删除文字，按 Ctrl+Shift+D（macOS 上为 ⇧⌘D）。显示出来的已删除文字不能编辑；在其中选择只会复制已删除的文字，在周围正文中的选择也不会包含它。

要恢复已删除的文字，右键点击标记或显示出来的文字，选择“恢复已删除的文字”。标记旁边新输入的文字会保留。

部分模型会给出无语音段，这些位置以单独的标记显示在正文中。

### 查看时间与置信度

按住 Ctrl（macOS 上为 ⌘）可以查看鼠标所指的文字，或光标处、选区内的文字。正文会为查看的内容描出轮廓，进度条会标出对应的时间范围。稍后会出现浮动提示，显示置信度、无语音概率、原文和时间范围。设置中可以改为在信息栏中显示这些信息，也可以隐藏无需关注的概率。

按住 Ctrl（⌘）时点击文字可以从该处播放，按 Enter 则从当前查看的文字处播放。超出媒体时长的时间戳以红色显示，表示这部分无法播放。

### 右键菜单

右键点击 ▼ 标记、无语音段标记、选区、字词或自己输入的文字，会显示该位置可用的操作：

- 在删除标记和显示出来的已删除文字上，可以“恢复已删除的文字”或“展开/收起已删除的文字”。
- “替换为”列出同一媒体的其他转写在相同时间识别出的文字，选择后用它替换选区；在无语音段标记上，同一列表显示为“插入”。时间需要重叠到什么程度由“参考文字重叠阈值”设置决定。
- “词库替换”应用匹配的词库规则；“添加到词库”用单行选区创建一条规则。
- 当输入的文字中含有被删除的原文字符时，会出现“与原文对齐”。它把这些字符重新标记为原文，使它们恢复时间对应，显示的文字不变。
- 剪切、复制和粘贴。

项目忙碌时（例如正在保存或打开），会修改文字的操作不可用。

### 查找与替换

按 Ctrl+F（macOS 上为 ⌘F）在显示的正文中查找，按 Ctrl+H（macOS 上为 ⌥⌘F）同时显示替换栏。选中的单行文字会自动填入查找框。

- 在查找框中按 Enter 和 Shift+Enter，或按 F3 和 Shift+F3（macOS 上为 ⌘G 和 ⇧⌘G），跳到下一处和上一处。
- 用 Alt+C、Alt+W、Alt+P（macOS 上为 ⌥⌘C、⌥⌘W、⌥⌘P）切换“区分大小写”“整词”“保留大小写”。
- 在替换框中按 Enter 替换当前匹配；“全部替换”（Ctrl+Alt+Enter，macOS 上为 ⌥⌘Enter）替换所有匹配，并作为一步撤销。
- “添加到词库”会新建一条词库规则，并填入查找文字和替换文字。
- 按 Escape 关闭查找栏。

查找只搜索显示的正文，不包括收起或展开的已删除文字。“整词”把字母、数字和组合符号视为单词字符。中文和日文的词语之间没有空格，因此开启该选项后，匹配两侧必须是标点、空格或正文开头、结尾。“保留大小写”会按每处匹配的大小写形式（全部大写、全部小写或首字母大写）调整替换文字。

### 词库

词库是所有项目共用的一组替换规则，可以从“转写”菜单或按 Ctrl+L（macOS 上为 ⌘L）打开。每条规则把一段文字替换为另一段文字；替换文字留空即删除原文字。规则可以启用、停用、编辑、搜索和删除。

规则不会自动应用。在正文中右键点击，使用“词库替换”：

- 有选区时，规则会替换选区内所有互不重叠的匹配，并作为一步撤销。全选正文即可替换全文。
- 没有选区时，规则替换与光标相接的那一处匹配。

匹配逐字符精确比较，不区分词语，因此规则 a → b 也会匹配 banana 中的 a。要限制规则的范围，请把两侧的字符（例如空格）同时写进原文字和替换文字。

“导出…”将词库保存为 JSON。“导入…”接受同一 JSON 格式，或每行一条规则、原文字与替换文字之间用制表符分隔的 UTF-8 文本文件。导入的规则追加在已有规则之后，无效行和重复规则会被跳过并计数。词库文件无法读取时，可以“重试”，或选择“备份并重置…”，先保存原文件副本，再从空词库开始。

## 播放

在播放器中播放或暂停，使用进度条定位，并调整速度和音量。播放器会标示正在播放的文字；在设置中开启“随播放位置滚动”可以让它始终保持可见。

- F7 后退、F9 前进，跳转时长在设置中调整，跳转不会暂停或继续播放。按住按键可以连续跳转。
- 上一个词、下一个词（Alt+← 和 Alt+→）在转写词语之间跳转，方便反复聆听同一段。
- 上一个媒体、下一个媒体（Alt+↑ 和 Alt+↓）切换媒体。
- 播放模式决定一份媒体播放结束后的行为：播完当前停止、顺序播放、列表循环或单个循环。
- “开始播放时后退”让每次播放从起点之前稍早处开始，以便听清上下文。

开启音量稳定可以让小声内容更容易听清。它只影响听到的声音，不会改写媒体文件；强度可以在“高级”设置中调整。电平表可以显示原始音频、音量稳定后或最终输出的电平。

设置中还可以调整切换媒体或跳转字词后的播放状态、是否记住各媒体的播放进度、音频输出设备变化时是否暂停，以及音频同步偏移。如果标示的文字比声音提前或滞后，可以运行偏移测试进行校准。

## 查看历史转写结果

点击媒体行中的“转写列表”按钮，可以查看该媒体的所有结果，每份结果都附有开始时间和配置。选择一份结果即可在编辑器中显示它。

校对修改属于当前显示的结果。切换到另一份结果会清空所有修改，因此 Vestige 会先请你确认。删除当前显示的结果也会删除其修改。

## 保存与继续工作

首次保存时，为项目选择文件名和位置。之后项目每隔约 10 秒自动保存一次。使用“另存为”可以另存一份副本。设置中的“压缩项目文件”会去除 JSON 中的空白字符以减小文件体积。

“媒体路径保存方式”决定媒体位置的写法：

- 绝对路径：所有媒体使用绝对路径。
- 项目文件夹内使用相对路径（默认）：项目所在文件夹及其子文件夹中的媒体使用相对路径，其他媒体使用绝对路径。
- 尽可能使用相对路径：所有媒体都使用相对路径，无法表示时（例如 Windows 跨盘）保留绝对路径。

相对路径以项目文件所在的文件夹为起点。此设置从下次保存起生效，不会移动或复制媒体。分享或备份项目时，请一并带上媒体，并保持它们与项目文件的相对位置。

关闭项目、打开另一项目或退出应用时，Vestige 会询问如何处理未保存的修改。保存失败时，可以重试或选择其他位置。

## 设置与阅读文档

设置包括界面语言、项目文件、同时转写的任务数、编辑、播放、主题和音量稳定等选项。浅色和深色主题各有三种颜色：强调色、背景色和文字色，界面中的其他颜色（如表面、边框）都由这三种颜色推导而来。拖动视频下方的分隔条可以调整视频预览的高度。

本文档开头显示文件的实际位置，之后是根据标题自动生成的目录。点击其他本地文档的链接会在当前窗口打开，使用“返回”可回到上次的阅读位置。网页链接会在浏览器中打开。

## 执行器与模型文件名称

### whisper.cpp

whisper.cpp 用于运行 Whisper 系列语音识别模型，包括 Tiny、Base、Small、Medium、Large 及其量化版本。必须使用 whisper.cpp 支持的 GGML 模型文件；原始 PyTorch 权重和 ONNX 模型不能直接使用。

```text
whisper-small/
    model.bin
```

将下载的模型文件（例如 ggml-small.bin）更名为 model.bin。Vestige 使用这个固定名称查找模型。重命名不会转换文件格式。

**从旧版本升级**：已有的 Whisper 模型文件夹（包括在应用内下载的模型）需要将 ggml-base.en.bin 改名为 model.bin。文件内容和文件夹名称保持不变，无需转换或重新下载。

### sherpa-onnx

sherpa-onnx 用于运行兼容的离线 ONNX 语音识别模型，例如 Paraformer、Zipformer / Transducer、CTC 和 SenseVoice。请选择官方标注为离线识别的导出版本；任意 ONNX 文件、流式识别模型和语音合成模型都不能使用。具体支持范围还取决于后端版本。

应用内下载的 Sherpa 后端包含 sherpa-onnx-vad 工具。自行准备的后端文件夹可以不包含它，此时 Vestige 会把音频切分为有时长上限的窗口，并在较安静的位置选择边界。VAD 只用于决定在哪里切分音频，不会丢弃任何音频。

模型文件名称与后端参数对应：去掉参数名开头的 --，再加上 .onnx。例如，Paraformer 的 model.onnx 需要更名为 paraformer.onnx。下表列出 Vestige 能识别的名称；模型文件夹中只需放入该模型实际使用的文件，不需要表中的所有名称。

```text
sherpa-paraformer-zh/
    paraformer.onnx
    tokens.txt

zipformer/
    encoder.onnx
    decoder.onnx
    joiner.onnx
    tokens.txt
```

| FireRedASR | `fire-red-asr-encoder.onnx`, `fire-red-asr-decoder.onnx` |
| Cohere Transcribe | `cohere-transcribe-encoder.onnx`, `cohere-transcribe-decoder.onnx` |
| FunASR Nano | `funasr-nano-encoder-adaptor.onnx`, `funasr-nano-llm.onnx`, `funasr-nano-embedding.onnx` |
| Qwen3 ASR | `qwen3-asr-encoder.onnx`, `qwen3-asr-conv-frontend.onnx`, `qwen3-asr-decoder.onnx` |

模型需要词表时，词表必须命名为 tokens.txt。FunASR Nano 和 Qwen3 ASR 需要的 tokenizer 文件夹分别命名为 funasr-nano-tokenizer 和 qwen3-asr-tokenizer，其中的文件保持原样。

每个文件夹只放一个模型，编码器、解码器、词表等文件必须来自同一套发布文件。量化或其他导出版本也需要使用上表中的名称；带 .int8 等后缀的文件不会被自动选用。Moonshine 各版本所需的文件不同，请按对应版本的官方示例准备。

## 执行器参数

在转写配置或预设编辑器中逐行添加参数。在“键”中填写带开头 -- 的参数名（或支持的短选项），在“值”中填写参数值。不带值的开关参数将“值”留空。不要填写完整命令行，也不要额外加命令行引号。

| 键 | 值 |
| --- | --- |
| `--language` | `auto` |
| `--threads` | `4` |

以上示例为 whisper.cpp 设置语言和线程数。sherpa-onnx 常用的参数包括 --provider 和 --decoding-method。可用参数随模型和后端版本变化，请参阅下方链接的文档。

Vestige 会提供音频输入、模型文件和输出路径，不要在参数中重复指定。whisper.cpp 的 -f / --file、-m / --model 和 -of / --output-file 由 Vestige 管理。

更多参数帮助、示例值和后端说明请参阅[参数说明](params.zh-cn.md)。

## 常见问题

- **找不到模型**：检查所选文件夹以及文件名称和扩展名，删除解压时多出的一层文件夹。系统隐藏扩展名时，注意文件名不要变成 .onnx.onnx 或 .bin.bin。
- **模型加载失败**：核对执行器、离线模型格式、各文件的版本和词表是否匹配。重命名只帮助 Vestige 找到文件，不能转换模型格式。
- **下载失败或已取消**：重试即可。请查看控制台输出，检查网络连接以及模型目录能否写入。不要将下载未完成的文件用于转写。
- **任务看似停滞**：无法确定总体进度时，进度条会持续活动而不显示百分比；模型加载等阶段也可能暂时没有输出。请查看可复制的控制台输出。
- **媒体缺失或已更改**：在媒体行中选择“重新定位”。如果文件内容已更改，原有转写可能不再与录音对应。
- **词库无法读取**：修复文件后选择“重试”，或选择“备份并重置…”，保留副本后重新开始。
- **标示的文字与声音不同步**：在播放设置中运行音频同步偏移测试。
